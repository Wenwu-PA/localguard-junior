# Соответствие экзаменационному ТЗ

Основа: прикреплённое задание «Пара 18. Настройки проекта dotnet при использовании Windows Forms. Подготовка к экзамену».
Тема согласовывается с преподавателем. Название на скриншоте: «Родительский контроль и аудит безопасности ПК».

| Требование | Что есть в проекте |
| --- | --- |
| ОС Windows 10/11, .NET, C# | C# WinForms, создаётся `dotnet new winforms` |
| Графический интерфейс | 3 вкладки, кнопки, поля ввода и журнал |
| Прогресс выполнения | `ProgressBar` на вкладке проверки файлов |
| Потоки и асинхронность | `Parallel.ForEachAsync` с максимум 5 работниками, `Task.Run` для контроля процессов |
| Синхронизация | `lock` для списка результатов, `Interlocked.Increment` для счётчика |
| Работа с процессами | Получение списка процессов, завершение выбранных программ |
| Windows API | Прямой P/Invoke не нужен: применены классы .NET |
| Публикация на GitHub | Подготовлен локальный Git-репозиторий, README и команды публикации |
| Защита проекта | `docs/DEFENSE.md` с объяснениями и вопросами |

## Какие функции из темы реализованы

- Проверка текстовых файлов на запрещённые слова: **реализована** в выбранной папке и подпапках.
- Замена слов на звёздочки: **реализована в копиях**, оригиналы остаются нетронутыми.
- Проверка игр и закрытие запрещённых: **реализована** по именам запущенных процессов при явно включённом контроле.
- Проверка слов из чатов: **демонстрационная версия только внутри своего окна**; чужие мессенджеры не считываются.

Это учебный прототип; не следует представлять его как полноценный родительский контроль.
