# LocalGuard Junior

**Тема экзаменационного проекта:** «Родительский контроль и аудит безопасности ПК».

Простое учебное приложение на **C# / .NET 10 / Windows Forms** для Windows 10/11.
В репозитории уже находится готовый WinForms-проект (`LocalGuardJunior.csproj`) со всеми исходными файлами. Visual Studio и сторонние библиотеки не требуются.

Это демонстрация тем курса «Системное программирование», а не полноценный антивирус или средство скрытого наблюдения.

## Возможности

### 1. Проверка файлов

- Выбор папки для проверки, включая подпапки.
- Поиск введённых пользователем слов в `.txt`, `.log`, `.md`, `.csv`.
- Замена найденных слов на звёздочки **в отдельных копиях**. Оригиналы не изменяются.
- Прогресс проверки и текстовый отчёт.
- Обработка до пяти файлов параллельно.

### 2. Контроль запущенных программ

- Пользователь вводит имена программ (процессов) через запятую.
- После явного подтверждения приложение проверяет процессы раз в две секунды.
- Если обнаружен процесс из списка, программа пытается его завершить.
- Есть кнопка выключения контроля и журнал действий.

**Предупреждение:** принудительное завершение процесса может привести к потере несохранённых данных. Не используйте для системных программ.

### 3. Демонстрационный чат

- Запрещённые слова указываются на вкладке «Проверка файлов».
- На вкладке «Чат (демо)» **верхнее светло-жёлтое поле — ввод сообщения**, а **большое белое поле ниже — история**.
- Введите сообщение в верхнее жёлтое поле и нажмите «Отправить» или Enter (Shift+Enter — перенос строки).
- Запрещённые слова скрываются звёздочками, рядом показывается число замен.

**Ограничение:** приложение не читает переписку из Telegram, Discord, браузеров или других программ. Фильтруются только сообщения внутри демонстрационного чата.

## Запуск

**Требования:** Windows 10/11, установленный **.NET 10 SDK** (`dotnet --version`).

В терминале PowerShell, открытом в корне репозитория:

```powershell
dotnet run --project .\LocalGuardJunior.csproj
```

Проект уже содержит файл `.csproj`, поэтому никаких команд создания проекта, копирования исходников или дополнительных скриптов не требуется. При первом запуске `dotnet run` автоматически выполняет стандартную компиляцию приложения.

## Пример проверки

1. Откройте вкладку **«Проверка файлов»**, укажите папку `examples` и слова `дурак, грубость`.
2. Нажмите **«Начать проверку»** и дождитесь завершения. Путь к отчёту появится в окне.
3. Для проверки вкладки **«Контроль программ»** запустите пустой Блокнот, укажите `notepad` и подтвердите включение контроля. Сначала сохраните все данные.
4. В демо-чате напишите `это грубость` — слово заменится на `********`.

## Где сохраняются результаты

В папке `Документы/LocalGuardResults/<дата_время>/`:

- `report.txt` — отчёт о проверке;
- обработанные копии файлов с заменёнными словами.

## Изученные технологии

| Технология | Для чего применяется |
| --- | --- |
| `Windows Forms` | Окно, вкладки, кнопки и индикатор выполнения |
| `Process` | Получение и завершение запущенных процессов |
| `Task`, `async/await` | Выполнение операций без блокировки интерфейса |
| `Parallel.ForEachAsync` | Проверка нескольких файлов параллельно (до пяти) |
| `Interlocked.Increment` | Безопасное увеличение общего счётчика |
| `lock` | Защита общего списка результатов |
| `Progress<int>` | Отображение прогресса в интерфейсе |
| `CancellationTokenSource` | Остановка фоновой проверки |
| `Regex` | Поиск и замена слов |

Прямые вызовы Windows API через P/Invoke не понадобились: используемых возможностей .NET достаточно для демонстрации.

## Ограничения

- Приложение работает только пока его окно открыто; фоновой службы Windows нет.
- Обрабатываются только поддерживаемые текстовые файлы размером до 2 МБ.
- Нет мониторинга других мессенджеров, скрытых перехватчиков ввода или обхода прав Windows.
- Для работы с процессами используются права текущего пользователя.
