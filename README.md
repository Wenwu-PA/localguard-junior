# LocalGuard Junior

Простой учебный проект на C# и Windows Forms для экзамена по **системному программированию**.
Тема: **«Родительский контроль и аудит безопасности ПК»**.

Приложение рассчитано на Windows 10/11. Это **демонстрация** системного программирования,
а не настоящий антивирус, скрытое средство наблюдения или готовое средство родительского контроля.

## Что умеет

1. **Проверка файлов**: сканирует выбранную папку и подпапки (`.txt`, `.log`, `.md`, `.csv`),
   находит слова из списка, заменяет их звёздочками в **копиях** и создаёт текстовый отчёт.
   Оригиналы не меняются.
2. **Контроль программ**: при включённом контроле каждые две секунды проверяет
   запущенные процессы с указанными пользователем именами и завершает их.
   Перед запуском предупреждает о возможной потере несохранённых данных.
3. **Демо-чат**: заменяет запрещённые слова в сообщениях, написанных **только в самом приложении**.
   Не считывает переписку из браузера, Telegram, Discord и других программ.

## Технологии для защиты

- `dotnet new winforms` — создание проекта без Visual Studio;
- `Process.GetProcessesByName`, `Process.Kill` — работа с процессами;
- `async` / `await`, `Parallel.ForEachAsync` — асинхронная обработка файлов;
- `MaxDegreeOfParallelism = 5` — до пяти параллельных работников;
- `Interlocked.Increment` — безопасное изменение общего счётчика;
- `lock` — защита общего списка результатов;
- `Progress<int>` и `ProgressBar` — обновление интерфейса из фоновой работы;
- `CancellationTokenSource` — остановка проверки и контроля.

`Windows API` через P/Invoke не используется: по условиям экзамена его следует применять
только при необходимости, а для этих функций хватает стандартного .NET.

## Установка и запуск

Нужны **Windows 10/11** и **.NET SDK 10** (проверка: `dotnet --version`).
Visual Studio и дополнительные NuGet-библиотеки не нужны.

Откройте PowerShell в папке репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File .\create-project.ps1
```

Скрипт вызывает **именно**:

```powershell
dotnet new winforms --name LocalGuardJunior --output LocalGuardJunior --no-restore
```

Затем копирует C#-файлы и выполняет `dotnet build`. Запуск:

```powershell
dotnet run --project .\LocalGuardJunior
```

Если проект уже создан, а исходники были изменены:

```powershell
powershell -ExecutionPolicy Bypass -File .\update-sources.ps1
```

## Как проверить

1. Вкладка **«Проверка файлов»**: выберите папку `examples`, оставьте слова
   `дурак, грубость` и нажмите «Начать проверку».
2. Дождитесь `100%` и откройте путь к `report.txt`, показанный в интерфейсе.
   Исправленные копии будут рядом в этой же папке результатов.
3. Вкладка **«Контроль программ»**: для безопасного теста сначала откройте
   пустой Блокнот (без несохранённых данных), введите `notepad`, включите
   контроль и подтвердите действие. Блокнот будет закрыт.
4. Вкладка **«Чат (демо)»**: введите «это грубость», нажмите «Отправить»;
   слово заменится на `********`.

**Осторожно:** контроль процессов может принудительно завершить программу и
потерять её несохранённые данные. Не добавляйте системные процессы.

## Где результаты

`Документы/LocalGuardResults/дата_время/`

- `report.txt` — имена файлов и количество замен;
- копии файлов — только если были найдены запрещённые слова.

## Структура

```text
LocalGuardJunior/
├── src/
│   ├── Program.cs            # точка входа WinForms
│   ├── MainForm.cs           # интерфейс и управление
│   ├── TextFilter.cs         # проверка слов
│   └── FileScanService.cs    # параллельная проверка файлов
├── examples/                 # тестовые файлы
├── docs/DEFENSE.md           # объяснение кода и вопросы к защите
├── docs/REQUIREMENTS.md      # соответствие экзаменационному ТЗ
├── create-project.ps1        # dotnet new winforms + сборка
├── update-sources.ps1        # обновление существующего проекта
├── .gitignore
└── README.md
```

После `create-project.ps1` появляется папка `LocalGuardJunior/` с `.csproj`.
Она исключена из Git, потому что формируется автоматически из `dotnet new winforms`.
В репозитории хранятся исходники и скрипты воспроизводимой сборки.

## Ограничения

- Работает только пока открыто окно, без системной службы и автозапуска.
- Не обходит ограничения Windows, не читает чужие чаты и не пишет нажатия клавиш.
- Проверяются только текстовые файлы выбранной папки, размер одного файла до 2 МБ.
- Нужные права доступа к файлам и процессам должны быть у текущего пользователя.
- Задание о «контроле переписки» реализовано как **демонстрационный чат**,
  а не перехват сообщений из сторонних программ.
